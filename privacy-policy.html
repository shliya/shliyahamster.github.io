隱私權政策

發文小助手（Live Assistant）｜最後更新：2026 年 8 月 24 日

摘要：本應用程式是一個安裝在你自己電腦上的桌面工具。 它沒有伺服器，也不會把你的資料傳送給我們或任何第三方。 所有資料都只存在你的電腦裡，你隨時可以自行刪除。

1. 本服務是什麼

發文小助手是一個在使用者電腦本機執行的桌面應用程式，用途是協助內容創作者 把自己原創的貼文與影片，一次發佈到多個社群平台 （X／Twitter、Threads、YouTube、Facebook 粉絲專頁）。

本應用程式沒有後端伺服器。 所有網路連線都是由使用者的電腦直接送到各社群平台的官方 API， 不會經過我們或任何中介伺服器。

2. 我們蒐集哪些資料

我們（開發者）不蒐集任何資料。本應用程式沒有分析工具、沒有回報機制、沒有錯誤追蹤服務。

應用程式會在你的電腦本機儲存以下資料，純粹為了讓功能可以運作：

資料項目用途儲存位置
各平台的授權權杖（access token / refresh token） 代表你發佈內容 本機，經作業系統金鑰加密
已連結帳號的名稱與頭像網址 在介面上顯示目前連到哪個帳號 本機
排程中的貼文內容與時間 時間到時自動發佈 本機
最近 200 筆發送紀錄 讓你查看成功／失敗結果 本機
你選擇的圖片／影片檔案路徑 上傳時讀取檔案 本機（檔案本身不會被複製）

3. 資料存在哪裡

所有資料儲存在你電腦的使用者資料夾中 （Windows 為 %APPDATA%\live-assistant\data.json）。

授權權杖使用作業系統提供的加密機制保護 （Windows 為 DPAPI），加密金鑰綁定你的 Windows 使用者帳戶。 即使有人複製了這個檔案到另一台電腦，也無法解密其中的權杖。

4. 我們如何使用各平台的 API

本應用程式僅執行使用者主動要求的動作：

  • 發佈內容：把使用者自行撰寫、且自己擁有的內容，發佈到使用者本人已授權的帳號
  • 上傳媒體：把使用者選擇的本機圖片或影片上傳到其本人的帳號
  • 讀取帳號基本資料：僅取得已授權帳號的名稱與頭像，用於在介面顯示目前連結的是哪個帳號，避免發錯帳號

本應用程式不會：

  • 蒐集、儲存或分析任何平台上的公開資料或他人內容
  • 讀取時間軸、搜尋結果或任何非授權帳號本人的資料
  • 將任何內容顯示給授權帳號本人以外的任何人
  • 將任何資料轉售、分享或提供給第三方
  • 進行情緒分析、機器學習訓練或任何形式的資料分析
  • 在未經使用者主動操作的情況下自行發佈內容

5. YouTube API 服務

本應用程式使用 YouTube API 服務。使用本應用程式的 YouTube 相關功能， 即表示你同意受 YouTube 服務條款 約束。

Google 如何處理資料，請參閱 Google 隱私權政策。

你可以隨時透過 Google 安全性設定頁 撤銷本應用程式對你 YouTube 帳號的存取權。

透過本應用程式上傳影片前，使用者必須主動勾選聲明， 確認上傳內容為其本人擁有的原創內容，且符合 YouTube 社群規範。

6. Meta 平台服務（Facebook 粉絲專頁 與 Threads）

本應用程式使用 Meta 的 Graph API 與 Threads API，僅執行以下動作：

  • Facebook 粉絲專頁：讀取使用者可管理的粉專清單 （pages_show_list、pages_read_engagement）， 並將使用者自行撰寫的內容發佈到其選擇的粉專 （pages_manage_posts）
  • Threads：讀取已授權帳號的名稱與頭像 （threads_basic），並發佈使用者自行撰寫的內容 （threads_content_publish）

本應用程式不會讀取粉專的洞察報告、訊息、留言或任何粉絲資料， 也不會讀取使用者本人帳號以外的任何內容。取得的粉專存取權杖僅加密儲存於 使用者本機，不會傳送到任何伺服器。

你可以隨時撤銷授權： Facebook 應用程式與網站設定、 Threads 帳號設定。

7. 你如何刪除自己的資料

因為所有資料都只存在你自己的電腦，你隨時可以完全自行刪除，不需要向任何人提出申請：

  • 解除單一帳號：在應用程式的「帳號設定」中按「移除」，該帳號的權杖會立即從本機刪除
  • 刪除全部資料：直接刪除 %APPDATA%\live-assistant\ 這個資料夾
  • 撤銷平台端授權：到各平台的應用程式授權管理頁面移除授權 （Google、 X、 Threads、 Facebook）

由於我們從未取得你的任何資料，因此沒有任何資料需要我們代為刪除。 若你仍希望提出資料刪除請求，可透過下方聯絡方式與我們聯繫，我們將於 30 天內回覆。

8. 兒童隱私

本應用程式並非針對 13 歲以下兒童設計，我們不會在知情的情況下向兒童蒐集任何資料。

9. 政策變更

若本政策有所變更，我們會更新本頁面的「最後更新」日期。重大變更將於應用程式內告知。
